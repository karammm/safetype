# Support

- **Documentation:** https://karammm.github.io/safetype/docs/
- **Questions and ideas:** [GitHub Discussions](https://github.com/karammm/safetype/discussions)
- **Bugs, missed words, false positives:** [open an issue](https://github.com/karammm/safetype/issues/new/choose)
- **Native speakers:** help [review a language pack](https://github.com/karammm/safetype/issues?q=is%3Aissue+is%3Aopen+label%3A%22native+speaker+review%22)
- **Security issues:** report privately. See [SECURITY.md](SECURITY.md)

## Supported versions

All packages share one version number and follow semantic versioning.

| Version | Support |
| --- | --- |
| Latest minor (`1.x`) | Bug fixes, dictionary corrections and security fixes |
| Previous minor | Security fixes for 3 months after the next minor ships |
| Older | Unsupported. Please upgrade (minor releases don't break your code) |

Platforms tested in CI: Node.js 18, 20, 22 and 24; Python 3.9–3.13; Chromium, Firefox and WebKit; React 18,
Vue 3.5, Angular 19 and 22. The full policy is in the [docs](https://karammm.github.io/safetype/docs/guide/support).

SafeType is maintained by volunteers. Issues get a first response within a week where possible, and security
reports within 3 business days.
