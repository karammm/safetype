# Angular example

A zoneless Angular 22 app using `provideSafeType`, the `safeType` directive with `ngModel` and reactive forms,
`safeTypeValidator` and the `safeType` pipe.

```bash
pnpm install && pnpm build                          # from the repository root
pnpm --filter @safetype/example-angular-app start    # http://localhost:4200
```
